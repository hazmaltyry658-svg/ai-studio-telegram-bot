# AI Studio Telegram Bot — النسخة الجاهزة للتشغيل

هذا المشروع يحول بوت تيليجرام إلى استوديو مصغر:
- وصف نصي → فيديو AI
- كلمات + نوع موسيقي → أغنية AI
- دمج الأغنية مع الفيديو
- اختيار المقاس: عمودي 9:16 / مربع 1:1 / أفقي 16:9
- سجل للطلبات في SQLite
- أزرار عربية
- رسائل حالة أثناء التنفيذ
- حماية أساسية من إرسال أكثر من مهمة للمستخدم في الوقت نفسه

## مهم جدًا
البوت لا يعمل وحده بمجرد وضع Token من BotFather. توليد الفيديو والموسيقى يحتاج مفاتيح API من الخدمات الخارجية، وقد تكون مدفوعة حسب الخدمة والخطة.

المشروع يستخدم:
1. Telegram Bot API للبوت.
2. Replicate لتوليد الفيديو.
3. ElevenLabs Music لتوليد الأغنية.
4. FFmpeg لدمج الصوت والفيديو.

المشروع لا يستنسخ صوت فنان حقيقي بعينه. خانة "الفنان/المرجع" في البوت تُستخدم كمرجع موسيقي عام فقط، مثل:
"طرب عربي حديث، صوت رجالي دافئ، إيقاع هادئ".
إذا أدخل المستخدم اسم فنان، الكود يحوله إلى وصف عام ولا يطلب تقليد صوته.

## التشغيل على ويندوز
1. ثبّت Python 3.11 أو أحدث.
2. ثبّت FFmpeg وأضف مجلد bin إلى PATH.
3. انسخ `.env.example` إلى `.env`.
4. ضع Token البوت من BotFather.
5. ضع مفاتيح Replicate و ElevenLabs.
6. افتح Terminal داخل المجلد وشغّل:
   pip install -r requirements.txt
7. شغّل:
   python app/bot.py

## أوامر البوت
/start
/help
/video
/song
/history
/cancel

بعد /video سيرشدك البوت:
الوصف → المقاس → المدة → إنشاء الفيديو.

بعد /song:
الكلمات → النوع/المزاج → المرجع الموسيقي العام → المدة → إنشاء الأغنية.

بعد إنشاء أغنية وفيديو، يمكن استخدام /mix لإرسال آخر نتيجة مدمجة إذا كان لديك الملفان.

## ملاحظة عن Telegram
Telegram Bot API يدعم إرسال الفيديو والملفات حتى 50MB وفق الوثائق الحالية. إذا تجاوز الناتج 50MB، الكود يحاول ضغط الفيديو قبل الإرسال.

## الإنتاج الحقيقي
للاستخدام العام، شغّل البوت على VPS/Render/Railway أو سيرفر آخر بدل إبقاء الكمبيوتر الشخصي مفتوحًا.
